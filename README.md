e-Serbisyong Tañong

An online barangay request management system for Tañong, Marikina City. Built as a capstone/thesis project at STI College Cubao (BS Information Technology).

Live demo: https://e-serbisyong-tanong.vercel.app

About

e-Serbisyong Tañong replaces manual, paper-based barangay transactions with a web app. Residents can request documents, book appointments, and stay updated on barangay announcements online, while barangay staff manage everything from an admin side.

Features

Resident side

Registration with email verification
Login and password reset
Profile management
Browse barangay services
Submit document requests
Book appointments
Notifications

Admin side

Admin dashboard
Manage and process resident requests
Manage users and user verification
Manage services
Admin account management
Barangay announcements
Tech Stack
Front end: HTML, CSS, JavaScript
Back end/database: Firebase Realtime Database (real-time data storage and updates)
Deployment: Vercel
Version control: Git and GitHub
